# Decoherence Model Parameter Estimator

An interactive application for simulating entanglement dynamics, decoherence/recoherence processes, and initial system-environment correlations in a two-spin bosonic dephasing model with PyTorch and PySide6.

## Scientific Background

This implementation is based on the theoretical framework presented in:

> V. V. Ignatyuk, A. R. Kuzmak, A. I. Smetana, and Ch. Samorodov, *"Separability and quantum concurrence in the two-spin dephasing model at various initial system preparations"*, Condensed Matter Physics (2026).

The simulator models two qubits coupled to a common bosonic thermal bath via pure dephasing ($H = H_S + H_B + H_I$), supporting:
- **Pure benchmark initial state** $\rho_S(0) = |+,+\rangle\langle+,+|$ (Appendix A).
- **Mixed correlated initial states** generated by special non-selective quantum measurements $\Omega_m = |\varphi_m\rangle\langle\psi_m|$ (Section 5 & Appendix B), where the Gram operator $G = \sum_r \Omega_r \Omega_r^\dagger = B^T B^*$ is either a non-identity diagonal matrix ($G \neq I_4$) or the identity matrix ($G = I_4$).

## Features

- **PyTorch Engine (`torch.float64` / `torch.complex128`)**:
  - Automatic generation of measurement subset probabilities $|a_{r1}|^2$ on the capped simplex ($0 \le |a_{r1}|^2 \le \frac{1}{2}$, $\sum_r |a_{r1}|^2 = 1$) and matching unitary matrices $A = (a_{rk})$.
  - L-BFGS optimization of the $4 \times 4$ complex measurement matrix $b_{rk}$ for both anisotropic diagonal ($G \neq I_4$) and identity ($G = I_4$) Gram operators.
  - Pure-PyTorch Gauss–Legendre quadrature for the bath decoherence function $\gamma(t)$, dynamic phase $\Phi(t)$, indirect spin-spin coupling $\Delta(t) = \Phi(t) - Kt$, and correlational contributions $\gamma_{nm}^{\text{cor}}(t)$ and $\chi_{nm}(t)$.
- **Interactive PySide6 GUI**:
  - Real-time sliders and spinboxes for inverse temperature $\beta = 1/(k_B T)$, qubit transition frequency $\omega_0$, coupling strength $\lambda$, Ohmicity index $s$ (sub-Ohmic $s < 1$, Ohmic $s = 1$, super-Ohmic $s > 1$), cut-off frequency $\omega_c$, and maximum evolution time $t_{\max}$.
  - Live multi-panel plots tracking **Wootters Concurrence** $C(t)$, **Peres–Horodecki Negativity** $\mathcal{N}(t)$, **System Purity** $\mathcal{P}(t) = Tr[\rho_S^2(t)]$, **Von Neumann Entropy** $S_{\text{vN}}(t)$, decoherence functions, and phase shifts.
  - Built-in tensor inspector displaying $|a_{r1}|^2$, $b_{rk}$, $G$, and $\rho_S(0)$ alongside characteristic relaxation times.

## Usage

Launch the interactive simulator:

```bash
python dephasing_gui.py
```

### Controls Overview
- **Thermostat & Two-Spin Parameters**: Adjust $\beta$, $\omega_0$, $\lambda$, $s$, $\omega_c$, and $t_{\max}$ to observe transitions between monotonic decoherence and short-time coherence/entanglement enhancement (recoherence).
- **Initial State & Gram Operator**: Switch between `Diagonal Gram (G != I)`, `Identity Gram (G = I)`, and `Pure Benchmark State`, adjust the diagonal anisotropy spread, or sample new measurement parameters with a chosen RNG seed.
- **Generated Tensors Tab**: Inspect exact numerical values, trace normalization, and eigenvalues of $\rho_S(0)$ and $G$.

## Architecture

| Component | Responsibility |
| :--- | :--- |
| `QuantumStateGenerator` | Samples $|a_{r1}|^2$, constructs unitary $A$, optimizes $b_{rk}$ via L-BFGS, and evaluates $\rho_S(0)$. |
| `DephasingPhysicsEngine` | Evaluates bath integrals, time evolution $\rho_S^{\text{tot}}(t)$, $C(t)$, $\mathcal{N}(t)$, $\mathcal{P}(t)$, $S_{\text{vN}}(t)$, and relaxation times. |
| `DephasingMainWindow` | PySide6 user interface with synchronized parameter sliders, persistent Matplotlib artists, and matrix inspector. |
